# Feather Browser v0.6 — Glyph Bitmap Cache Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the three-level font cache by adding per-(char, size) glyph bitmap caching with a bundled `advance_width` field, then updating the render loop to use the new API so each paint makes zero fontdue rasterizer calls after warmup.

**Architecture:** Two sequential tasks. T1 extends `GlyphBitmap` with `advance_width: f32`, adds a `GLYPH_CACHE` thread-local, and exposes `rasterize_cached` in `src/engine/font.rs`. T2 switches the render loop in `src/engine/render.rs` to call `rasterize_cached` and read `glyph.advance_width` directly, eliminating the separate `advance_width(ch)` per-character call.

**Tech Stack:** Rust 2021, fontdue 0.9. No new crates.

**Spec:** `docs/superpowers/specs/2026-10-21-feather-v0.6-design.md`

- [ ] **Step 6: Add `rasterize_cached` method**

In `src/engine/font.rs`, find `pub fn rasterize` and append `rasterize_cached` immediately after it (inside `impl FontMetrics`, before the closing `}`):

```rust
pub fn rasterize_cached(&self, ch: char) -> Arc<GlyphBitmap> {
    let key = (ch as u64) << 32 | self.size.to_bits() as u64;
    GLYPH_CACHE.with(|cache| {
        let mut map = cache.borrow_mut();
        if let Some(g) = map.get(&key) {
            return g.clone();
        }
        let g = Arc::new(self.rasterize(ch));
        map.insert(key, g.clone());
        g
    })
}
```

Key construction: `char` is at most 21 bits (U+10FFFF), so `ch as u64` fits in the upper 32 bits; `f32::to_bits()` fills the lower 32 bits. No collision is possible.

fn test_render_loop_pen_advances_with_cached_glyphs() {
    use feather::engine::{
        css::CssParser,
        html::HtmlParser,
        layout::{LayoutEngine, Rect},
        render::Painter,
        style::style_tree,
    };
    use feather::engine::css::CssColor;

    let dom = HtmlParser::parse("<p>Hello</p>");
    let sheet = CssParser::parse("p { font-size: 16px; color: black; display: block; }");
    let styled = style_tree(&dom.root, &sheet);
    let layout = LayoutEngine::build(&styled, 400.0);
    let viewport = Rect { x: 0.0, y: 0.0, width: 400.0, height: 100.0 };
    let canvas = Painter::paint(&layout, viewport, 16.0);

    // Count columns (x positions) that contain at least one non-white pixel
    let non_white_cols = (0..canvas.width)
        .filter(|&x| (0..canvas.height).any(|y| canvas.pixels[y * canvas.width + x] != CssColor::WHITE))
        .count();

    // "Hello" is 5 chars; if pen advance works (advance_width > 0 per char),
    // rendered glyphs should span at least 10 distinct columns
    assert!(
        non_white_cols >= 10,
        "Text 'Hello' should span ≥10 non-white columns; got {non_white_cols} \
         (advance_width may be 0, stacking all chars at x=0)"
    );
}

### Task 2: `overflow: hidden` in render

**Files:**
- Modify: `src/engine/render.rs` (`render_box`, `render_box_plain`, add `has_overflow_hidden`)
- Test: `tests/engine_render_test.rs` (append 2 `#[cfg(feature = "feather-renderer")]` tests)

**Interfaces:**
- Consumes: `LayoutBox`, `BoxType`, `Value::Keyword`, `Dimensions::border_box()`
- Produces: children fully outside a parent with `overflow: hidden` are skipped

**Note:** Known limitation to document: children that *partially* overlap the parent boundary are still rendered in full — sub-pixel clipping requires a canvas scissor rect not yet available.

- [ ] **Step 1: Write 2 failing render tests**

Append to `tests/engine_render_test.rs` (inside `#[cfg(feature = "feather-renderer")]`):

```rust
    #[test]
    fn test_display_none_produces_no_pixels() {
        let dom = HtmlParser::parse("<div style=\"display: none; background-color: red; width: 100px; height: 100px;\"></div>");
        let sheet = CssParser::parse("");
        let styled = style_tree(&dom.root, &sheet);
        let layout = LayoutEngine::build(&styled, 800.0);
        let canvas = Painter::paint(&layout, 800, 600);
        let red_count = canvas.pixels.chunks(4)
            .filter(|p| p[0] == 255 && p[1] == 0 && p[2] == 0)
            .count();
        assert_eq!(red_count, 0, "display: none must produce zero red pixels");
    }

    #[test]
    fn test_overflow_hidden_skips_fully_outside_child() {
        // Parent: 10x10 at origin with overflow:hidden and white background
        // Child: 200x200, starts at x=100 (fully outside parent in X)
        // Child has red background — must not appear
        let html = "<div style=\"width: 10px; height: 10px; overflow: hidden; background-color: white; position: absolute; top: 0; left: 0;\">\
                    <div style=\"width: 200px; height: 200px; background-color: red;\"></div>\
                    </div>";
        let dom = HtmlParser::parse(html);
        let sheet = CssParser::parse("");
        let styled = style_tree(&dom.root, &sheet);
        let layout = LayoutEngine::build_with_viewport(&styled, 800.0, 600.0);
        let canvas = Painter::paint(&layout, 800, 600);
        // pixel at (100, 100) must not be red
        let idx = (100 * 800 + 100) * 4;
        if idx + 3 < canvas.pixels.len() {
            assert_ne!(canvas.pixels[idx], 255,
                "pixel at (100,100) must not be red — child is fully outside parent with overflow:hidden");
        }
    }
```

- [ ] **Step 3: Add `has_overflow_hidden` helper to render.rs**

In `src/engine/render.rs`, add before `render_box`:

```rust
fn has_overflow_hidden(lb: &LayoutBox) -> bool {
    use crate::engine::css::Value;
    match &lb.box_type {
        BoxType::Block(s) | BoxType::Inline(s) =>
            matches!(s.properties.get("overflow"), Some(Value::Keyword(k)) if k == "hidden"),
        BoxType::Anonymous => false,
    }
}
```

## Subsystem 1: Async Fetch Pipeline

### Problem

`glib::idle_add_local` with `ControlFlow::Continue` busy-polls the GTK main loop — the closure fires hundreds of times per second until the fetch thread delivers its result.

### Solution

Replace with `glib::MainContext::channel` — the GTK main-thread callback fires exactly once when the fetch thread sends.

### Interface

No changes to `src/engine/network.rs` — `fetch_page(url: &str) -> Result<FetchResult, FetchError>` is unchanged.

### Implementation

In `feather_renderer.rs`, both `fetch_and_render_url` and `load_url` replace their `mpsc::channel + idle_add_local` block:

```rust
// BEFORE (busy-poll):
let (tx, rx) = std::sync::mpsc::channel::<Result<String, String>>();
std::thread::spawn(move || { let _ = tx.send(...); });
glib::idle_add_local(move || {
    match rx.try_recv() {
        Ok(result) => { ...; glib::ControlFlow::Break }
        Err(TryRecvError::Empty) => glib::ControlFlow::Continue,  // ← busy-poll
        Err(_) => glib::ControlFlow::Break,
    }
});

// AFTER (event-driven):
let (sender, receiver) = glib::MainContext::channel::<Result<network::FetchResult, network::FetchError>>(
    glib::Priority::DEFAULT
);
std::thread::spawn(move || { let _ = sender.send(network::fetch_page(&url_clone)); });
receiver.attach(None, move |result| {
    match result {
        Ok(r) => renderer.render_page(&r.html, &url),
        Err(e) => {
            let error_html = format!(
                "<html><body><h2>Load failed</h2><p>{}</p></body></html>",
                html_escape(&e.0)
            );
            renderer.render_page(&error_html, &url);
        }
    }
    glib::ControlFlow::Break
});
```

### Tests

No new test file needed — the change is observable by the absence of CPU spin. The existing `cargo test --no-default-features` suite must continue to pass.

```rust

```

### Types

```rust
// SPDX-License-Identifier: AGPL-3.0-or-later

pub struct GlyphBitmap {
    pub pixels: Vec<u8>,   // alpha channel, row-major, 0=transparent 255=opaque
    pub width: usize,
    pub height: usize,
    pub x_offset: i32,     // horizontal bearing (px from glyph origin)
    pub y_offset: i32,     // vertical bearing from baseline (positive = above)
}

pub struct FontMetrics {
    font: fontdue::Font,
    pub size: f32,           // px
    pub ascent: f32,         // px above baseline
    pub descent: f32,        // px below baseline (positive value)
    pub line_height: f32,    // ascent + descent + leading (1.2× em recommended)
    pub space_advance: f32,  // width of U+0020 SPACE
}

impl FontMetrics {
    /// Load the embedded Noto Sans font at the given pixel size.
    pub fn load(size: f32) -> Self

    /// Horizontal advance width for a single glyph in px.
    pub fn advance_width(&self, ch: char) -> f32

    /// Sum of advance widths for all characters in `s`.
    pub fn measure_str(&self, s: &str) -> f32

    /// Rasterize one glyph to a GlyphBitmap.
    pub fn rasterize(&self, ch: char) -> GlyphBitmap
}
```

### Font size from CSS

`FontMetrics::load(size)` is called from `render_page` with the font-size resolved from the style tree root. Default: 16.0 px. Later tasks can thread per-element font sizes through `PlacedInlineItem`.

### `render.rs`: blit_glyph

```rust
/// Alpha-blend a glyph onto the canvas at (canvas_x, baseline_y).
pub fn blit_glyph(canvas: &mut Canvas, glyph: &GlyphBitmap, x: i32, baseline_y: i32, color: CssColor)
```

For each pixel `(gx, gy)` in the glyph bitmap:
- `canvas_px = (x + glyph.x_offset + gx, baseline_y - glyph.y_offset + gy)`
- alpha-blend using glyph alpha as coverage: `out = color * alpha + bg * (1 - alpha)`

## Subsystem 3: Inline Formatting Context

### Overview

CSS defines two formatting contexts: block (existing) and inline (new). When a block box contains only inline-level content (text nodes and inline elements), it runs an **inline formatting context**: text is broken into words, words are placed left-to-right on line boxes, and a new line starts when the available width is exhausted.

### New types in `layout.rs`

```rust
/// One horizontal line within an inline formatting context.
pub struct LineBox {
    pub items: Vec<PlacedInlineItem>,
    pub y: f32,        // top of line relative to containing block's content origin
    pub height: f32,   // max line-height of all items on this line
    pub baseline: f32, // ascent from the top of this line box
}

/// A single word (or whitespace run) placed on a line.
pub struct PlacedInlineItem {
    pub text: String,
    pub x: f32,        // left edge relative to containing block's content origin
    pub width: f32,    // measured advance width
    pub font_size: f32,
    pub color: CssColor,
}
```

`LayoutBox` gains:

```rust
pub line_boxes: Vec<LineBox>,  // non-empty when this box ran an inline formatting context
```

### InlineFormattingContext

```rust
pub struct InlineFormattingContext<'a> {
    pub font: &'a FontMetrics,
    pub available_width: f32,
}

impl<'a> InlineFormattingContext<'a> {
    /// Collect all inline content from `node`'s subtree and lay it into line boxes.
    /// Returns (line_boxes, total_height).
    pub fn layout(&self, node: &StyledNode) -> (Vec<LineBox>, f32)
}
```

### Line-breaking algorithm

```
cursor_x = 0.0
current_line_items = []
lines = []
line_y = 0.0

For each text run in the inline subtree (depth-first):
  words = split on whitespace (preserve leading/trailing space as separate items)
  for word in words:
    w = font.measure_str(word)
    if cursor_x + w > available_width AND cursor_x > 0:
      flush current_line_items → LineBox(y=line_y, height=font.line_height)
      line_y += font.line_height
      cursor_x = 0.0
      current_line_items = []
    push PlacedInlineItem { text: word, x: cursor_x, width: w, ... }
    cursor_x += w + font.space_advance

flush last line
return (lines, line_y + font.line_height)
```

### Integration with block layout

`layout_block` inspects children of a block-level box:

- **All children are inline** → run `InlineFormattingContext::layout()`, store result in `lb.line_boxes`, set `lb.dimensions.content.height` to returned total height.
- **Any child is block-level** → existing stacking algorithm. Inline siblings of block children are wrapped in an anonymous block box (standard CSS anonymous box rule).
- **Mixed:** collect consecutive inline children into an anonymous block, then continue with the next block child.

### render.rs changes

`render_box` checks `lb.line_boxes`:

```rust
if !lb.line_boxes.is_empty() {
    let origin_x = lb.dimensions.content.x;
    let origin_y = lb.dimensions.content.y;
    for line in &lb.line_boxes {
        let baseline_y = (origin_y + line.y + line.baseline) as i32;
        for item in &line.items {
            let x = (origin_x + item.x) as i32;
            for (i, ch) in item.text.chars().enumerate() {
                let glyph = font.rasterize(ch);
                let char_x = x + font.advance_width_cumulative(&item.text, i) as i32;
                blit_glyph(canvas, &glyph, char_x, baseline_y, item.color);
            }
        }
    }
} else {
    render_text(canvas, lb);  // grey-bar fallback for anonymous/unstyled boxes
}
```

`Painter::paint` receives a `&FontMetrics` argument.

## Subsystem 4: Scrolling

### `Inner` struct additions

```rust
scroll_offset: f32,   // px from document top; 0.0 on page load
doc_height: f32,      // total layout height recorded after each render_page
```

### Scroll controller (in `FeatherRenderer::new()`)

```rust
let scroll_ctrl = gtk4::EventControllerScroll::new(
    gtk4::EventControllerScrollFlags::VERTICAL
);
let inner_scroll = Rc::downgrade(&inner);
scroll_ctrl.connect_scroll(move |_, _dx, dy| {
    if let Some(rc) = inner_scroll.upgrade() {
        let mut s = rc.borrow_mut();
        let viewport_h = s.drawing_area.height() as f32;
        let max_scroll = (s.doc_height - viewport_h).max(0.0);
        s.scroll_offset = (s.scroll_offset + dy as f32 * 40.0).clamp(0.0, max_scroll);
        s.drawing_area.queue_draw();
    }
    glib::Propagation::Stop
});
drawing_area.add_controller(scroll_ctrl);
```

### `render_page` changes

After `LayoutEngine::build`:

```rust
// Record document height for scroll clamping.
{
    let mut s = self.inner.borrow_mut();
    s.doc_height = layout_root.dimensions.margin_box().height;
    s.scroll_offset = 0.0;  // reset on new page
}

// Apply scroll offset to viewport.
let scroll_offset = self.inner.borrow().scroll_offset;
let viewport = Rect { x: 0.0, y: scroll_offset, width: w as f32, height: h as f32 };
```

The rasterizer already clips to the viewport rect — no oversized buffer, no change to `Canvas` or `Painter`.

### Tests

Scroll logic is GTK-event-driven and tested via `cargo check`. Integration correctness verified manually. `doc_height` recording is unit-testable via a helper on `FeatherRenderer` if needed.

## Subsystem 5: CSS Shorthand Expansion

### Changes in `src/engine/css.rs`

A single `expand_shorthand(prop: &str, value: &str) -> Vec<(String, Value)>` function is called from the declaration parser. Returns one entry for longhand properties, 2–4 entries for shorthands.

### Shorthands

**Box model (margin / padding / border-width):** 1–4 value box shorthand.

```
1 value:  all four sides
2 values: top+bottom, left+right
3 values: top, left+right, bottom
4 values: top, right, bottom, left
```

```rust
fn expand_box_shorthand(prefix: &str, values: &[Value]) -> Vec<(String, Value)> {
    let (top, right, bottom, left) = match values.len() {
        1 => (v[0], v[0], v[0], v[0]),
        2 => (v[0], v[1], v[0], v[1]),
        3 => (v[0], v[1], v[2], v[1]),
        _ => (v[0], v[1], v[2], v[3]),
    };
    vec![
        (format!("{}-top", prefix),    top),
        (format!("{}-right", prefix),  right),
        (format!("{}-bottom", prefix), bottom),
        (format!("{}-left", prefix),   left),
    ]
}
```

**`font` shorthand:** parse `[font-weight] font-size[/line-height] font-family`.

```
font: bold 16px sans-serif
  → font-weight: bold
  → font-size: 16px
  → font-family: sans-serif (ignored — one embedded font)
```

**`font-size`:** already parsed as `Value::Length` by the existing parser — no change needed. Flows into `FontMetrics::load(size)` via style tree property lookup.

### Selector additions

**Descendant combinator** (`div p`): selector `A B` matches `B` that has an ancestor matching `A`.

**Child combinator** (`div > p`): selector `A > B` matches `B` whose direct parent matches `A`.

These require a small refactor of the selector matching in `style_tree`: instead of matching only the current node's own simple selectors, pass the ancestor chain and check combinator rules.

```rust
pub enum Combinator {
    Descendant,   // whitespace
    Child,        // >
    Adjacent,     // + (v0.5)
}

pub struct CompoundSelector {
    pub simple: SimpleSelector,
    pub combinator: Option<(Combinator, Box<CompoundSelector>)>,
}
```

Existing single-segment selectors are `CompoundSelector { simple, combinator: None }` — fully backwards-compatible.

## Out of Scope for v0.4

- `vertical-align` beyond baseline (top/middle/bottom deferred to v0.5)
- Right-to-left text
- `white-space: nowrap` / `pre`
- Image layout (`<img>` decoded and painted)
- Subresource loading (CSS `@import`, external stylesheets)
- WebKit content filters
- Per-element font families (one embedded font only)
- Adjacent sibling combinator (`+`)

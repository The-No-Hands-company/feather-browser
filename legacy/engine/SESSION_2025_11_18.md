## Technical Details

### Architecture
```
Promise (struct)
├── [[PromiseState]] - Arc<Mutex<PromiseState>>
├── [[PromiseFulfillReactions]] - Arc<Mutex<VecDeque<PromiseReaction>>>
├── [[PromiseRejectReactions]] - Arc<Mutex<VecDeque<PromiseReaction>>>
└── [[PromiseIsHandled]] - Arc<Mutex<bool>>

PromiseReaction (struct)
├── capability: Option<Arc<PromiseCapability>>
├── reaction_type: Fulfill | Reject
└── handler: Function | Identity | Thrower

PromiseCapability (struct)
├── promise: Promise
├── resolve: Rc<dyn Fn(JSValue)>
└── reject: Rc<dyn Fn(JSValue)>
```

## Lessons Learned

### Technical
1. **Arc/Mutex is powerful but has overhead** - Consider lock-free alternatives for hot paths
2. **Rc<dyn Fn> is ergonomic** - Good balance of flexibility and performance
3. **ECMAScript spec is detailed** - Following it exactly produces correct behavior
4. **Tests drive quality** - 8 tests caught 3 bugs during development

### Process
1. **Spec-first development works** - Reading ES2025 spec prevented mistakes
2. **Incremental building** - Start with core, add features progressively
3. **Type system helps** - Rust caught many potential JS bugs at compile time
